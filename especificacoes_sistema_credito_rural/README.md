## Uso

Copie os arquivos para uma pasta `docs/specs` do projeto ou utilize o contexto principal como `CLAUDE.md`, conforme a estratégia adotada.

O arquivo `12-PROMPT-EXECUCAO-CLAUDE-CODE.md` orienta o Claude Code a iniciar pela auditoria e implementar as fases incrementalmente.

## Observação

As regras de negócio ainda não confirmadas estão marcadas como propostas ou devem ser registradas como `OPEN QUESTION`. Elas precisam ser validadas antes de serem tratadas como requisitos definitivos.
